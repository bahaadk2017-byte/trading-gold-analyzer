# نظام تحليل وتداول أزواج الفوركس

نظام قيد البناء لتحليل أزواج الفوركس واختبار الاستراتيجيات، يتقدّم بمراحل
نحو التداول الورقي — **ولا شيء بعده دون موافقة صريحة منفصلة**.

## الحالة الآن

| | |
|---|---|
| **المرحلة** | 1 من 9 — عقد البيانات وبوابات الجودة ✅ |
| **التنفيذ الحقيقي** | ⛔ **غير مُصرَّح به ولا مُبنيّ.** لا يوجد كود إنشاء أوامر في المستودع |
| **مصدر بيانات القرار** | MT5 / XM Global — قراءة فقط |
| **الاختبارات** | 41 اختبار وحدة ناجح + تحقّق حيّ 28/28 |

> ⚠️ **حساب MT5 المتصل حقيقي** (XM Global، رافعة 1:1000، `trade_allowed: true`).
> كل الكود هنا قراءة فقط، لكن انظر [سؤال 2 في التدقيق](docs/audit/2026-10-23-state-and-sources.md#2-أهم-نتيجة-في-هذا-التقرير-حسابك-الحقيقي-متصل-الآن)
> بخصوص الانتقال إلى حساب تجريبي.

## البنية

```
src/fxcore/
  contracts.py          عقد البيانات الموحّد + البصمة + حقل info_available_at
  clock.py              قياس انحراف توقيت السيرفر عن UTC (قِيس: +3h)
  quality.py            9 بوابات جودة. الافتراضي NO_TRADE
  sources/mt5_source.py محوّل MT5 — قراءة فقط، بلا أي دالة أوامر
scripts/
  verify_data_path.py   تحقّق حيّ من المسار كاملًا
evidence/               مخرجات الفحص الأولي (probe*.py)
tests/                  41 اختبارًا، كل منها يثبّت عيبًا مُقاسًا
```

## التشغيل

```bash
python -m pytest tests/ -q
```

```bash
python -u scripts/verify_data_path.py
```

يتطلّب منصّة MT5 مفتوحة ومسجّلة الدخول. لا يحتاج أي مفتاح أو كلمة مرور.

## المبادئ

1. **«لا صفقة» هي الحالة الافتراضية.** فشل أي بوابة = `NO_TRADE` مع ذكر السبب.
2. **بيانات القرار من الوسيط وحده.** TradingView والأخبار سياق وعرض، لا قرار.
3. **لا رقم بلا أصل:** المصدر، وقت الحدث، وقت توفّر المعلومة، التأخر، الترخيص، البصمة.
4. **رمز التحليل ≠ رمز التنفيذ.** `EURUSD` غير قابل للتداول؛ `EURUSDm#` حجم عقده 1,000 لا 100,000.
5. **سلطة المخاطر لا تُشارَك.** لا وكيل يملك تعديل حدود المخاطر.
6. **لا ترقية تلقائية بين المراحل.**

## ما لا يدّعيه هذا النظام

لا دقة بلا أخطاء · لا ربح مضمون · لا «order flow حقيقي» للفوركس
(`tick_updates` هو عدد تحديثات أسعار الوسيط، لا حجم تداول).
