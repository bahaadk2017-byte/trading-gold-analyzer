# نظام تحليل وتداول أزواج الفوركس

نظام قيد البناء لتحليل أزواج الفوركس واختبار الاستراتيجيات، يتقدّم بمراحل
نحو التداول الورقي — **ولا شيء بعده دون موافقة صريحة منفصلة**.

## الحالة الآن

| **الفريق** | ✅ **14 وكيلًا جاهزًا** في [`.claude/agents/`](.claude/agents/) — انظر [`TEAM.md`](TEAM.md) |

| **مصدر بيانات القرار** | MT5 / XM Global — قراءة فقط |
| **الاختبارات** | 72 اختبار وحدة ناجح + تحقّق حيّ 28/28 |

## التشغيل

```bash
python -u scripts/analyze.py
```

```bash
python -m pytest tests/ -q
```

يتطلّب منصّة MT5 مفتوحة ومسجّلة الدخول. لا يحتاج أي مفتاح أو كلمة مرور.

## المبادئ

1. **«لا صفقة» هي الحالة الافتراضية.** فشل أي بوابة = `NO_TRADE` مع ذكر السبب.
2. **بيانات القرار من الوسيط وحده.** TradingView والأخبار سياق وعرض، لا قرار.
3. **لا رقم بلا أصل:** المصدر، وقت الحدث، وقت توفّر المعلومة، التأخر، الترخيص، البصمة.
4. **رمز التحليل ≠ رمز التنفيذ.** `EURUSD` غير قابل للتداول؛ `EURUSDm#` حجم عقده 1,000 لا 100,000.
5. **سلطة المخاطر لا تُشارَك.** لا وكيل يملك تعديل حدود المخاطر.
6. **لا ترقية تلقائية بين المراحل.**

## ما لا يدّعيه هذا النظام

لا دقة بلا أخطاء · لا ربح مضمون · لا «order flow حقيقي» للفوركس
(`tick_updates` هو عدد تحديثات أسعار الوسيط، لا حجم تداول).
