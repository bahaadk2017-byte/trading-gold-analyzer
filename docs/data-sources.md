# سجل مصادر البيانات

**مالك الملف:** `data-source-steward` · **آخر تحديث:** 2026-10-23
**القاعدة:** لا رقم يدخل قرارًا إلا من مصدر `approved_for_decisions = true`.
البوابة `gate_source_approved` تُنفّذ هذا بنيويًا، لا بالثقة.

---

## 1. مصادر معتمدة للقرار

| المصدر | يوفّر | الترخيص / الحق | التأخر | الحالة |
|---|---|---|---|---|
| **MT5 / XM Global** `XMGlobal-MT5 12` | `bid/ask`، مواصفات العقد، السبريد، المبادلة، الهامش، التاريخ | بيانات حساب المستخدم عند وسيطه — لا إعادة نشر | مقيس: ~12 مللي ثانية للجلب | ✅ **معتمد** |

**القيود المقيسة:** توقيت السيرفر UTC+3 (يُقاس كل تشغيل) · سقف `maxbars = 100000`
والطلب عنده يُعيد صفرًا · `EURUSD` غير قابل للتداول و`EURUSDm#` حجم عقده 1,000 ·
`real_volume` بلا معنى · `margin_initial` يُعيد 0.0 ·
التاريخ الصالح: H1/H4 من 2019، D1 من 2008، M15 من 2023 ·
**السبريد التاريخي لكل شمعة غير متاح** — تكاليف الاختبار تقديرية متحفّظة.

## 2. مصادر سياق — ممنوعة من القرار

| المصدر | يوفّر | الترخيص / الحق | التأخر | الحالة |
|---|---|---|---|---|
| **TradingView MCP الرسمي** `mcp.tradingview.com/mcp` | شارت، فرز، تقويم اقتصادي، أخبار، قوائم مراقبة، تنبيهات | OAuth 2.1 بحساب المستخدم · يتطلّب **Essential أو أعلى** (التجريبي لا يكفي) | ⚠️ **غير معلن في الوثائق** | ⚠️ **سياق فقط** |
| **نشرات البنوك المركزية** (7 نشرات) | أخبار وبيانات رسمية برابط ووقت نشر | نشرات RSS عامة للتوزيع · مصادر رسمية | ساعات إلى أيام | ⚠️ **سياق فقط، موسوم `untrusted`** |

### ثغرتان في وثائق TradingView الرسمية — لم تُحلّا

1. **تأخر البيانات غير معلن.** صفحة الوثائق لا تذكر هل `get_ohlcv` للفوركس لحظي أم مؤجَّل.
2. **لا نص عن الاستعمال الآلي أو إعادة النشر.** صفحة MCP لا تتضمّن شروطًا إطلاقًا.

**القرار:** الاستعمال التفاعلي للشارت والبحث والعرض فقط. **قبل أي استعمال آلي
متكرّر، يجب قراءة شروط خدمة TradingView واتفاقيات بيانات السوق** — وهي ليست في صفحة MCP.
حتى ذلك الحين: `approved_for_decisions = false`.

**قيد تقني مفيد لنا:** لا يمكن إنشاء تنبيهات webhook عبر MCP (يتطلّب 2FA غير مدعوم).
فمسار «تنبيه → webhook → تنفيذ آلي» **مغلق** — وهذا يمنع طريقًا للتنفيذ بلا بوابات.

هذا هو الالتفاف الذي لا نفعله. تُسجَّل كفجوة مُعلَنة في كل تشغيل.

## 3. مصادر مرفوضة

| المصدر | سبب الرفض |
|---|---|
| **`tradingview-mcp` المستقل** | أسعاره من **Yahoo** (وسطية، بلا `bid/ask` ولا مواصفات عقد) · نقاط نهاية غير رسمية · **غير مرتبط بحساب المستخدم إطلاقًا** · تحذير سلسلة توريد في وثائقه (نسخ مزيّفة تجلب برمجيات خبيثة) |
| **Yahoo Finance** للفوركس | سعر وسطي لا ينفّذ · اختبار عليه ثم تنفيذ على XM = اختبار نظام آخر |
| **Alpha Vantage / yfinance** (مسار AI-Trader) | نفس السبب: لا `bid/ask` ولا مواصفات عقد |
| **المستويات التجريبية في Agent-Reach** (Twitter/Facebook/Instagram) | «قد تفشل في أي وقت» — فشل صامت · وتحمل خطر حظر الحساب |
| **أي كشط** | ممنوع بقرار، لا استثناء |

## 4. إعداد TradingView

أُضيف الخادم إلى [`.mcp.json`](../.mcp.json):

```json
{ "mcpServers": { "tradingview": { "type": "http", "url": "https://mcp.tradingview.com/mcp" } } }
```

**ما عليك فعله:** عند بدء الجلسة التالية سيطلب Claude Code موافقتك على خادم
المشروع، ثم يفتح تسجيل دخول OAuth بحسابك في TradingView. **لا تحتاج مفتاح API،
ولن أطلب منك كلمة مرور.**

**إن لم يكن اشتراكك Essential أو أعلى** سيفشل الاتصال — وهذا بحد ذاته جواب،
والنظام يعمل كاملًا بدونه في المراحل 0 إلى 4.

حدود الاستهلاك المعلنة: ~100 طلب/دقيقة · OHLCV ≤5000 شمعة (افتراضي 300) ·
دفعة أسعار ≤50 رمزًا · صفوف الفرز ≤1000 · العناوين ≤200.
